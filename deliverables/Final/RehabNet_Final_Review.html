MOTIVATION
Home rehabilitation is unsupervised

Huge need

About 2.4 billion people live with a condition that benefits from rehabilitation (Cieza et al., Lancet 2020).

No one watching

Exercises are done at home: nobody checks form, counts repetitions or tracks progress.

Tools don't fit homes

Motion capture, depth cameras and wearables are accurate but costly or impractical.

Our idea

Use the phone or laptop camera the patient already has, with real-time pose estimation.

Goal: count, score and correct every repetition at home - and show the doctor objective progress.

SOLUTION
How RehabNet works
Camera

phone or laptop, in the browser

›
Pose

MediaPipe BlazePose: 33 body landmarks

›
Angles

11 joint angles, smoothed, 10 per second

›
Count & score

repetition counter, DTW + NCC vs correct reps

›
Feedback

spoken correction; doctor sees every session

Key point: video never leaves the patient's device - only 33 landmarks are sent to the server.

MILESTONE 3
A secure doctor-patient web app

Doctor portal

Create patients, prescribe exercises (side, sets, reps, sessions per week), review every repetition and the feedback given.

Patient portal

Demo clip, live skeleton, counter, movement gauge, score and spoken correction after every repetition.

Security

bcrypt passwords, 2-factor login (TOTP), lock-out, per-patient access control, encrypted session data, audit log.

Validated live: AUC 0.68 on unseen people; browser result = offline analysis (5 / 5 reps); 7 / 7 automated tests pass.

MILESTONE 4
Personal, and followed over weeks

Personal baseline

The patient's good reps from a supervised session join the references (AUC 0.705; alone only 0.58).

Adaptive counting

If the patient's range is below 70 % of the reference, the counter uses the patient's own thresholds.

Progress

Score and range-of-motion trend per week (improving / stable / worse) and weekly adherence.

Reports

One-click PDF report for the doctor or the patient; every export audit-logged.

DEPLOYMENT
Runs anywhere

Clinic laptop

One command: .\run_app.ps1 starts the app at localhost:8000. Works offline - all models served locally.

Phones on Wi-Fi

.\run_app.ps1 -Https serves the app over HTTPS so phone cameras can be used.

Cloud

Docker image behind HTTPS; PostgreSQL through one setting; secrets as environment variables.

CONCLUSION
Limitations and future work

Clinical pilot

Test with real patients and physiotherapists - all data so far is healthy volunteers.

Angle accuracy

About 15° from motion capture: a clinical aid, not a goniometer.

More measures

Frontal-plane knee angles for lunge errors; shoulder rotation.

Bigger library

New exercises need only a few correct reference recordings.

Outcome: every proposal objective was achieved except a clinical pilot.
